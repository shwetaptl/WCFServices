# WCFRESTWebService
REST Web Service in WCF

This project contains a web service that has one function called GetCustomers which returns a list of customers. And another console application that calls this web service and gets a list of customers and prints it in the console. 

In the web.config file  , binding = "webHttpBinding" make this web service a REST web service where you can hit a URL and get response in XML OR JSON.
